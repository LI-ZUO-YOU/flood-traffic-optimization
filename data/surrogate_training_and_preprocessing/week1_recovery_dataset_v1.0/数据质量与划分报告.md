# 数据质量与四类划分报告

## 1. 总体判定

数据可用于当前“代理模型认知不确定性—CVaR-R 抢通排序”的受控方法验证，未发现会阻断恢复状态样本生成的结构性错误。所有正式样本均取自 `SiouxFalls_UE_flood_models/data_connected/`，没有使用会导致正需求 OD 不可达的初版积水情景。

需要明确的研究边界是：当前数据与原计划中的“真实城区 OSM 路网＋真实/仿真城区 OD＋公开洪水风险图”不一致。Sioux Falls 是 24 节点、76 有向路段的经典算法基准，坐标也不代表真实地理位置。因此，这一版本能够支撑方法可行性和内部比较，但不能单独支撑真实城市外部有效性。若论文仍以 JCR Q2 为目标，建议在后续版本增加至少一个真实城区案例；若一个月内不增加，应在题目、摘要、方法和局限性中统一表述为 benchmark-based methodological case study。

## 2. 输入数据核查

| 项目 | 核查结果 |
|---|---|
| 节点与路段 | 24 节点、76 有向路段、38 双向物理道路；ID 唯一，映射完整 |
| OD | 528 个正需求 OD 对，总需求 360600；长表与 24×24 矩阵总量一致，无负值 |
| 积水实例 | 120 个，每个实例包含 38 条物理道路和 76 条有向路段记录 |
| 双向一致性 | 同一物理道路的两个方向具有相同深度和关闭状态 |
| 深度与关闭 | 深度均非负；`depth >= 0.30 m` 与 `is_closed=1` 完全一致 |
| 连通性 | 120 个正式情景均来自连通约束版本，正需求 OD 可达 |
| 情景划分 | 60 训练、20 校准、20 普通测试、20 严重测试，情景编号无重复 |
| 严重关键失效 | 18/20 个严重情景同时关闭至少两条流量或介数处于前四分位的道路 |

严重测试满足研究计划“至少部分情景包含高流量或高介数道路联合失效”的要求。剩余 2 个情景保留为普通严重空间簇，有助于避免严重集完全等同于人为关键道路攻击集。

## 3. UE 数值设置判定

原模型在洪水状态下使用 `relative gap=1e-4` 时，个别情景 2000 次迭代仍不能达到目标。为保证批量标签一致、计算预算可控，正式生成采用 `5e-4`：

- 20 个代表情景基准测试全部在 1000 次内收敛；
- 2400 个正式状态全部收敛；
- 47 个状态触发 3000 次迭代重试，最终均达标；
- 5 个情景与 `1e-4` 参考解比较，TSTT 相对差异最大 0.0920%，最小 0.0175%。

该数值误差相对于洪涝状态 TSTT 的数量级变化较小，可作为代理训练标签。论文方法部分必须报告这一容差，不能写成默认 `1e-6` 或暗示所有洪水状态达到更严格精度。

## 4. 恢复状态生成

每个状态由初始积水/关闭向量 `d` 与已恢复向量 `r` 组成。恢复子集来自随机恢复顺序的前缀，并对重复子集去重；当目标接近有限状态空间上限时，使用确定性子集枚举补齐。每个状态都保留来源轨迹、阶段、恢复顺序和 SHA-256 状态哈希。

样本量：

| 集合 | mild | moderate | severe | 合计 |
|---|---:|---:|---:|---:|
| train | 146 | 1354 | 0 | 1500 |
| calibration | 52 | 248 | 0 | 300 |
| test_id | 42 | 258 | 0 | 300 |
| test_severe | 0 | 0 | 300 | 300 |

轻度情景只有 1–3 条关闭道路，每个实例最多产生 2–8 个不重复恢复子集，因此轻度状态数量不能在不制造重复输入的情况下与中度状态平衡。本数据集选择完整保留所有轻度唯一状态，并用中度状态补足目标规模。后续训练应考虑严重度/情景权重，不应通过复制轻度行来“平衡”。

## 5. 无泄漏划分

划分在积水实例生成阶段已经固定：

- 训练：`scenario_id 1–60`；
- 校准：`61–80`；
- 普通测试：`81–100`；
- 严重测试：`101–120`。

最终检查显示，四类集合之间的 `scenario_id` 交集为 0，2400 个 `state_id` 和 2400 个状态哈希均唯一。同一初始洪涝场景的相邻恢复状态不会跨集合出现。

## 6. 最终质量门

- 四类样本数量精确匹配 1500/300/300/300；
- 2400 个状态全部有 UE 标签；
- 2400/2400 收敛，最大 relative gap 为 0.00049998252；
- 标签无缺失、无无穷值；
- 恢复标记均为初始关闭集合的子集；
- CSV 中所有道路列表采用 JSON 数组文本，空集合写为 `[]`；
- 原始输入未被改写，所有结果保存在独立输出目录。

## 7. 后续建议

第二周训练时建议把 `log_tstt_ratio` 作为主候选输出，同时保留 `normalized_tstt` 对照；所有标准化、特征选择和输出变换参数仅从训练集估计。模型选择完成后再一次性评价普通测试集；严重测试集只用于压力测试，不参与任何模型或校准参数选择。
